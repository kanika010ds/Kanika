## 🚀 Selected Work & Projects

### 🛰️ Satellite Crop Monitoring & Processing
- Developed satellite imagery download, ingestion, band extraction, and multispectral processing workflows for crop monitoring across six states.
- Generated crop-health mosaics and worked with **Sentinel-2** imagery for agricultural intelligence.

### 🌱 Crop Classification & Field Mapping
- Analyzed **NDVI-based crop phenology** to support crop classification, including paddy, wheat, and cotton.
- Applied **SAM2** for agricultural field boundary detection and produced raster and vector outputs for validation in **QGIS**.

### 💧 Vegetation & Water Analytics
- Developed, tested, and validated satellite-derived analytics APIs for **EVI, NRI, EVI2, DSWI, NDWI**, true color, and false color visualizations.

### 📷 Agricultural Computer Vision
- Built crop and disease detection workflows using **YOLO** and **OpenCV**.
- Annotated and preprocessed datasets using **Roboflow**; worked on image and live-stream analysis.

### 🧪 Soil Health Modeling
- Explored satellite-derived features and ML models (**SVM, Random Forest, Linear Regression**) to estimate soil properties including **NPK, organic carbon, pH, and electrical conductivity**.

### 🤖 Geospatial AI Chatbot & APIs
- Worked on chatbot workflows using **vector databases, semantic retrieval, and prompt engineering** for agricultural data queries.
- Developed **Flask REST APIs**, tested with **Postman**, and worked with **Docker** for deployment.

### 🌙 Infrared Image Colorization & Enhancement — *In Progress*
- Exploring methods to enhance infrared image detail and translate monochrome imagery into interpretable color representations.
- Focusing on preserving structural and semantic information for downstream object interpretation.
